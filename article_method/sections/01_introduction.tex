\section{Introduction}
\label{sec:introduction}

% ---------- ¶1: Motivation ----------
% Software repositories produce rich event data; PM + stochastic modeling
% offer in principle a path to predictive analytics on the SDLC.
% Cite: van der Aalst (process mining book), Vacanti (actionable agile metrics).
Software development lifecycle (SDLC) data is increasingly available in
machine-readable form across version control, issue trackers, code-review
systems and CI/CD platforms. Process mining (PM) and stochastic modeling
each offer mature techniques for analyzing such data; yet their joint
deployment for \emph{predictive} use in the SDLC remains rare.

% ---------- ¶2: Gap (from SLR) ----------
% Cite the companion SLR (Almeida de Oliveira et al., 2026):
% F4 — pipeline fragmentation: 1/404 confirmed primary studies jointly
% satisfies PM + stochastic + forecasting.
A recent systematic literature review across 5{,}783 deduplicated records
and 404 confirmed primary studies~\cite{almeida2026slr} reports that
only a single study jointly integrates process mining, stochastic
modeling, and forecasting for the SDLC. The literature is descriptively
rich but predictively fragmented: most works either discover process
models without forecasting, forecast lead times without process awareness,
or apply machine learning to features that ignore the underlying process
structure.

% ---------- ¶3: Contributions ----------
This paper addresses the pipeline-fragmentation gap by proposing
\textsc{PATHCAST}, a formally specified method that integrates event
log construction, process discovery, absorbing Markov chain estimation,
process-aware Monte Carlo simulation, and a machine-learning enhancement
component. Our contributions are:
\begin{enumerate}
    \item \textbf{C1.} A formal pipeline specification with contract-based
    stage composition (Section~\ref{sec:architecture}) and a correctness
    theorem under stated preconditions
    (Theorem~\ref{thm:pipeline-correctness}).
    \item \textbf{C2.} An empirically grounded stochastic model that
    couples a Markov transition kernel with empirical sojourn-time
    distributions (Section~\ref{sec:stages}), preserving the
    distributional shape observed in real software processes.
    \item \textbf{C3.} A novel family of features for delay prediction
    derived from PM and Markov analysis
    (Section~\ref{sec:ml-component}), complementing traditional mining
    software repositories (MSR) features.
    \item \textbf{C4.} Formal guarantees: asymptotic consistency,
    end-to-end distributional convergence, and an information-theoretic
    advantage over process-blind throughput-based Monte Carlo
    (Section~\ref{sec:properties}).
    \item \textbf{C5.} A closed-form numerical example
    (Section~\ref{sec:numerical-example}) that validates the analytical
    derivation against Monte Carlo simulation on a six-state SDLC chain.
\end{enumerate}

% ---------- ¶4: Scope (this is a method paper) ----------
This paper focuses on the \emph{formal specification} of the method and
its theoretical properties. The empirical evaluation of \textsc{PATHCAST}
across 48 open-source repositories, including comparison with four
baselines and statistical analysis of forecasting accuracy, is reported
in a companion paper. The evaluation protocol is summarized in
Section~\ref{sec:evaluation-plan}.
