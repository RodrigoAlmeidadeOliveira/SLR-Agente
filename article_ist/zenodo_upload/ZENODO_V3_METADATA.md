## Description (plain text / HTML simples)

```
Version 3 of the replication artefact for the systematic mapping study (Information and Software Technology). Corpus after ML complementary search, Wohlin snowballing to saturation, IC1 filter, and Phase-2 blind flips: n = 1710 included studies.

Search: five databases (Scopus, IEEE Xplore, ACM Digital Library, SpringerLink, Web of Science); eligibility window from 1 January 1994; searches executed 12 April 2026.

The package includes: search strings; deduplication, enrichment, and screening pipelines; LLM prompts and schemas; human verification and blind re-screen sheets (Phase-2 κ = 1.00, n = 117); caminho_completo protocols and decision sheets; RQ3 priority human extraction (293) plus suggestion-assisted core coding (1417); SPMF and venue summaries; canonical studies.json and included_studies_1710.csv; SEGRESS checklist.

PDFs of primary studies are not redistributed (copyright); DOIs are in corpus_n1710/included_studies_1710.csv.

Step-2 recall pre-registration: 10.5281/zenodo.24148068.
Cite all versions / concept DOI: 10.5281/zenodo.21939599.
```
