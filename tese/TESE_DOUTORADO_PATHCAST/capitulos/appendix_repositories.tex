\chapter{Evaluation Dataset: Repository List}
\label{app:repository-list}

This appendix lists the 48 open-source repositories selected for the
empirical evaluation described in Chapter~\ref{ch:methodology}
(Section~\ref{sec:dataset}). Selection followed the stratified sampling
protocol of Section~\ref{sec:selection-process}: 150 candidates from
SEART GitHub Search~\cite{seart2021}, criterion verification via the
GitHub REST API~\cite{github2023api}, and stratification across primary
language, project scale, governance model, and workflow maturity
(Table~\ref{tab:dataset-diversity}).

Forty-seven of forty-eight evaluation repositories had usable event logs after
the June 2026 harvest (see \texttt{repo\_manifest.json}).
\texttt{torvalds/linux} was collected but yields no process cases under the
Stage-1 filter (\texttt{min\_events=2}): the kernel project maintains issue
tracking on the Linux Kernel Mailing List rather than GitHub Issues.
Apache and Spring projects use Jira issue
transition history from Montgomery et al.~\cite{montgomery2022jira} in
place of GitHub Issues where noted. Table~\ref{tab:repo-manifest-summary}
lists per-repository Stage-1 case and event counts from the June~2026 harvest.
