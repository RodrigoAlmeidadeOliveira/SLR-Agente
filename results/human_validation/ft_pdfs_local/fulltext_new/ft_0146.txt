     An activity network (AN) is a graph where the nodes
  represent activities and edges represent precedence among
  activities. The most common precedence relation between
  two activities is the finish-to-start (FS), which restricts the
  start of execution of one activity to the termination of
  another. There are two main types of ANs: deterministic and
  non-deterministic. The deterministic activity network (DAN)
  is represented by a graph whose topology remains fixed as
  the activities are being executed. Examples of DANs include
  the widely known CPM and PERT networks.
     On the other hand, an activity network contains decision
  and repetition nodes which allow for constructions that, not
  only restrict the order of the activities, but also whether they
  are going to be executed or not and the number of times

     These two assumptions allow the determination of the
  execution time of software development processes described
  by WFPs with the same algorithm used in the solution of
  RCPSPs. The algorithm is used in conjunction with the
  Monte Carlo (MC) method to obtain an approximation of
  the distribution of a process execution time.
     The MC method is basically a sampling procedure over
  the universe of all possible executions of the process. Each
  sample is called a scenario. Hence a scenario is an instance
  of the WFP where every activity has a known duration and
  the outcoming branch of all decision nodes are defined. The
  application of the decision policy to a given instance allows
  us to determine, in a unique manner, the total execution time
  of the process instance.

  C. The algorithm GenerateDAN
     This algorithm is responsible for obtaining a determin-
  istic instance of the WFP by selecting one of its possible
  execution paths. This procedure first transforms the WFP
  into one of the possible RC-DANs, by replacing all decision
  nodes with a single branch, representing the realization of
  the decision. In a subsequent step, a constant duration value
  is sampled for each activity from the its duration PDF. The
  definition of a RC-DAN is exactly the same of a WFP, except
  for the fact that all decision nodes have been instantiated.
